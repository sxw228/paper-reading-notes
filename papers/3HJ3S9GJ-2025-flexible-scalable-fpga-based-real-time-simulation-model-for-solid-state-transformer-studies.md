# Flexible, Scalable FPGA-based Real-Time Simulation Model for Solid-State Transformer Studies

作者：Zerui Dong、Levi-John Lewis、Juan Paez-Alvarez、Aditya Ashok、Wei Li。出处：IEEE ECCE，2025。DOI：10.1109/ECCE58356.2025.11260145。Zotero key：3HJ3S9GJ。[pdf:E01]

> 证据说明：`[pdf:E..]` 对应源 PDF 物理页与 Eq./Fig./Table 定位；文末链接保留整页上下文。本文共 8 个物理页。§3、§9–§12中的解释、批评与研究方案属于阅读者分析。

## §1 — 研究问题与重要性

本文解决一个具体的平台问题：如何在同一 FPGA 实时仿真由大量 H 桥和双有源桥 DAB 组成的固态变压器 SST，同时保留每个单元独立门极、直流电容状态及可改变的串并联连接。DAB 通过高频变压器连接两个开关桥，兼顾电压变换和电气隔离；这使 SST 的开关数量与频率同时增加。作者面向电动车充电、直流配电和控制器硬件在环测试，把大量快动态安排到 FPGA，将电网和上层控制留在 CPU。[pdf:E01][pdf:E02]

难点不只是一次仿真算得快，还包括拓扑改变以后能否复用模型。本文把基本电力电子单元及其电容分开，通过信号映射组合成系统。其价值是让工程师用配置连接关系的方式构造不同 SST，再测试系统控制，而不必为每个连接重新设计整套 FPGA 求解器。[pdf:E03][pdf:E04]

## §2 — 前人工作与不足

作者沿用了 Li 与 Bélanger 的 MMC 等效电路思路：以受控电压源和二极管表示 H 桥，降低大量器件引入的计算负担；流水线实现则引用 Dong 等人的 MARS 实时仿真框架。前者提供单元的电气等价表达，后者提供在硬件中复用运算资源的工程方法。这些既有工作已构成本文的基础，本文重点是将它们组织成可配置的 SST 模型体系。[pdf:E02][pdf:E03][pdf:E08]

本文引用的 SST 拓扑综述和充电站研究说明实际系统包括 AC/DC、隔离 DC/DC 与不同端口组合。直接按全部开关建模，在 CPU 中按亚微秒推进很困难；针对单一拓扑固定搭建的模型又不适合快速试验连接方式。文章给出的解决路径是选择 HB、CHB、DAB/MAB 为组合单元，以电压、电流作为模块接口。论文没有给出传统 CPU 求解器与新平台在同一精度指标下的耗时表，因此“加速”在本文主要由实际实现步长与规模体现。[pdf:E02][pdf:E04]

## §3 — 重建作者的思考路径

可以从重复结构出发理解作者的选择。SST 看似有很多开关，但大部分开关在重复完成“把电容电压按极性接到交流端”这一操作。若逐个解开关节点，大量工作花在重复结构内部；若只保留平均功率，又会丢掉独立门极及 DAB 高频电流。受控电压源保留开关状态对端口的作用，为这两种粒度之间提供了可用位置。这个推理以文中 H 桥等效、独立门极和模块化拓扑为依据。[pdf:E02][pdf:E03]

下一步是认识到系统可变性主要体现在“谁给谁供电压、谁的电流汇入哪只电容”。于是，运算模块保持固定，连接关系由管理系统映射。慢速电网与高速 DAB 的时间尺度不同，再自然导向 CPU–FPGA 多步长组织。这里的核心设计判断是把电气模块和数据连接分开。[pdf:E04]

## §4 — 核心 Intuition

把每个桥臂压缩成由门极和电容电压决定的端口电压，再独立更新储能元件，就能把大电路拆成大量重复的小计算。FPGA 反复运行这些小计算，管理系统负责接线，CPU 负责较慢的外部电网与上层控制。这样，同一组计算模块能够覆盖多种 SST 连接方式。[pdf:E02][pdf:E03][pdf:E04]

## §5 — 具体方法与完整 Pipeline

以论文的中压交流转低压直流充电站模型为例：每相十个 HB–DAB 单元，三相共 30 个 HB、30 个 DAB，DAB 次级并联形成公共直流母线，总计 31 个电容。额定功率 3 MW，单元 100 kW，交流端 23 kV，HB 电容额定 2 kV，直流母线 800 V；系统参数见物理页4 Table II。[pdf:E04]

1. **构造单元等效。** H 桥被两条受控电压源加理想二极管支路替代。正插入输出电容电压，负插入输出其负值，旁路输出零；所有门极关闭时，电流方向选择二极管路径。DAB 两侧各有一组此类桥，变压器用考虑变比的电感、电阻简化，MAB 则增加并联等效支路。作者未展开只开一只开关的非常用模式。[pdf:E02][pdf:E03]
2. **读旧状态并生成桥端电压。** 管理系统把上一拍电容电压与门极送到 HB/CHB、DAB/MAB 模块，生成受控源的当前输出，再算电感电流，同时依据模块电流更新电容。接口连接随拓扑配置改变。[pdf:E03][pdf:E04]
3. **在 FPGA 映射重复计算。** 模型用 Xilinx 库块构造离散计算，通过流水线让一个函数实例处理多个单元。文章给出模块级结构，未报告运算字长、定点/浮点格式、具体流水线深度或 LUT/DSP/BRAM 占用。[pdf:E03][pdf:E05]
4. **安排多步长通信。** CPU 与 FPGA 经 PCIe 同步交换；FPGA 电压在一个 CPU 步长内平均后下采样给 CPU，CPU 电流在 FPGA 中保持一个 CPU 步长。该保持关系意味着高速模型得到的是分段常值的外部电流。[pdf:E04]
5. **分层控制与输出。** FPGA 运行电压均衡及脉冲生成，CPU 运行上层直流电压、功率、能量和电流控制。FPGA 可接 SFP 光纤和 I/O，CPU 可提供网络通信与配置界面。论文实际演示了模拟量输出及示波器采集，外接控制器闭环被作为平台能力与后续应用描述。[pdf:E04][pdf:E05][pdf:E06]

实际运行环境为 RT-LAB、OP5707XG 与 Virtex-7 VC707。FPGA 实现 64 个单元，案例启用其中 30 个；30 个 DAB 的模型步长为 40 ns，30 个 HB 为 240 ns，CPU 中电网、负载和上层控制为 50 µs。摘要的“最多64个 DAB”与本例“激活30个”应分别理解为实现容量陈述和已展示运行规模。[pdf:E01][pdf:E05]

## §6 — 核心数学推导

电容的电压变化来自净充入电荷，电感的电流变化来自两端电压积分。令桥开关函数为 (S)，它把桥交流端电流映射到直流侧，也把直流电压映射到交流侧。以物理页3 Eq.(4)–(6)为准，用离散下标重写为：

\[
v_{MV}[k]=v_{MV}[k-1]+\frac{T_s}{C_{MV}}
\{S_{HB}i_{HB}[k-1]-S_{DAB1}i_{DAB1}[k-1]\},
\]
\[
v_{LV}[k]=v_{LV}[k-1]+\frac{T_s}{C_{LV}}
\{S_{DAB2}i_{DAB2}[k-1]-i_{out}[k-1]\},
\]
\[
i_{L,DAB}[k]=i_{L,DAB}[k-1]+\frac{T_s}{L_{DAB}}
\{S_{DAB1}V_{DAB1}[k-1]-S_{DAB2}V_{DAB2}[k-1]\}.
\]

这里 (T_s) 是仿真步长，(C_{MV},C_{LV}) 为两端电容，(L_{DAB}) 为总等效电感，桥变量的定义与方向对应 Fig.3。原式没有为 (S) 显式写时间下标；上式保留这一排版事实，不自行推断其采样时刻。原 Eq.(6)中也没有电阻压降项，尽管 Fig.3 画出了 (R_{eq})。复现时应把“刊载递推式”和“含串联电阻的电气方程”作为需澄清的差异。[pdf:E03]

这些式子采用旧电流、旧电压更新状态，具有前向显式推进的结构：本拍不用同时解所有电容和电感未知量，因而容易铺成流水线。代价是步长要足够小，才能控制离散误差及端口保持误差。图中闭锁二极管的逻辑保留了桥在门极关闭时的电流通路，但全文未给出二极管过零判据或步内事件插值算法。[pdf:E02][pdf:E03]

## §7 — 实验设计与结论

**高频 DAB 能否运行？→ 单独观察高速电流和模拟输出 → 平台得到连续、稳定的波形。** 物理页5–6 Fig.7–8使用 50 kHz 门极、40 ns 步长检验 DAB，记录 FPGA 内部电流及模拟输出。模拟输出板为 2 MSPS，因此外部示波器链路的时间分辨率与内部40 ns模型推进不同；内部高速电流由 FPGA scope 观察。[pdf:E05][pdf:E06]

**充电负载变化能否由系统控制吸收？→ 负载降半再恢复 → 交流功率跟随且电容保持均衡。** 物理页6 Fig.9在5 s把直流负载由3 MW降到1.5 MW，10 s恢复；满载时 CHB 电容在额定值±5%，即±100 V范围内均衡，直流母线恢复至额定值。该案例使用 Table II 的 CHB 10 kHz、DAB 30 kHz门极设置，与前述50 kHz的 DAB 单元测试分开。[pdf:E04][pdf:E06]

**能否双向送电并独立调无功？→ 改变无功和有功方向 → 展示 V2G 运行。** 物理页7 Fig.10先在5 s把无功设定从0改为600 kVar，再在10 s把有功从吸收1.5 MW改为注入1.5 MW。作者报告 CHB 电容和直流母线电压维持在额定值±5%，分别对应±100 V和±40 V。[pdf:E07]

这些实验支持“所实现平台能实时运行这组电气模型和控制器，并产生合理闭环响应”。精度验证主要是波形行为与控制目标符合；全文没有给出相对于独立小步长详细模型或物理功率电路的误差统计。最大单元数与可支持最高开关频率被作者留作后续基准测试，资源利用表也未报告。[pdf:E05][pdf:E06][pdf:E07]

## §8 — Take-aways

**五句话。** 第一，重复的 H 桥和 DAB 适合用端口等效与独立状态更新降低计算量。第二，连接关系由管理系统映射，使硬件函数能够复用。第三，本例的 DAB、HB 与 CPU 运行于不同步长。第四，30个 HB–DAB 单元的负载变化和双向功率控制已在平台运行。第五，模型精度、容量上限和 FPGA 资源效率需要更有针对性的基准来定量判断。[pdf:E02][pdf:E04][pdf:E05][pdf:E06][pdf:E07]

**三句话。** 电气等效减少每个单元的计算，信号映射提供拓扑配置。流水线和多步长让高速变换器与较慢电网模型协同运行。文章的直接证据是平台运行与闭环响应，精度收益尚缺独立参考对照。[pdf:E03][pdf:E04][pdf:E05][pdf:E07]

**一句话。** 这是一套以可组合桥模型支撑 SST 实时研究的平台方案。[pdf:E01][pdf:E04]

## §9 — 最脆弱的假设

最关键的假设是：在50 µs内保持 CPU 给出的端口电流，并平均 FPGA 端口电压，仍能保留研究对象的重要系统交互。本文的外部交流源经阻抗连接，直流负载简化为电流源；这个边界相对平缓，给多速率接口提供了有利条件。[pdf:E04][pdf:E05]

如果把共享直流母线外部接入低阻抗电源、快速负载或另一台紧耦合变换器，端口电流可能在一个 CPU 步内明显改变。此时 FPGA 内部再细的 DAB 步长也无法恢复外部模型未提供的交互。这一假设一旦失效，平台对控制相互作用的结论会改变；论文尚无接口步长扫描或统一小步长参考实验。[pdf:E05][pdf:E07]

## §10 — 最小复现实验

一周内用单个 HB–DAB、两端电容及外部 RL 支路实现论文递推式和门极等效，然后构造统一小步长与 CPU保持/平均接口两个版本。先在相同低频负载事件下对齐，再扫描外部阻抗和接口周期。所需输入是 Table II 的单元参数及 Fig.3方向约定；电阻项应分别实现“打印公式版”和“电路方程版”，明确比较其影响。[pdf:E03][pdf:E04]

测量 DAB峰值电流、直流电压纹波、事件后功率恢复轨迹以及每次推进耗时。支持核心机制的结果应同时显示：桥等效在细步长下收敛到详细理想开关模型；引入多速率接口后，所关心的响应仍落在预先约定误差内。若只有闭环电压看似平稳，而峰值电流偏差随接口周期增大，则需要缩小平台适用的研究范围。本节提出实验设计，未执行复现。

## §11 — 最强反例设计

让两台并联 DAB 在低阻抗公共母线上执行不同相位调制，在保持平均功率基本相同的条件下扫描相位组合。对比详细小步长模型与本文保持/平均接口模型，检查桥间环流和公共电容纹波。平均电压、平均功率可以一致，高频环流却可能明显不同，因此这种反例直接检验“波形平稳就意味着关键动态被准确模拟”这一替代解释。

反例选择由本文公共母线、独立门极、信号平均三项结构共同决定。[pdf:E04][pdf:E05] 若差异只在超出本文关注带宽的局部开关细节，不能推翻其负载阶跃结果；若差异改变均压控制或功率方向变化的恢复轨迹，就触及平台作为系统控制验证工具的核心用途。

## §12 — Follow-up Research Bet

**主 idea：用单元相位组织构造可编程的 SST 端口频谱。** 新问题是：当总有功相同时，能否通过联合设计各 DAB 的载波相位与共享电容连接，把 SST 的高频纹波从副作用变成可操纵的端口特性，使一个功率硬件拓扑产生多种可辨识的交互行为？新能力是直接设计“对外呈现什么频谱”，研究目标从功率设定跟踪转向端口动态合成。

因果链是：独立门极改变各单元脉动电流的时序；并联电流在共享电容处叠加；相位相关性改变纹波分量与端口扰动传播；据此把载波相位和电容分组作为联合设计变量。本文管理系统已经提供连接映射与独立单元控制，Fig.7展示高速电流可观测，Fig.9–10展示系统级功率调节可运行，正好提供方法细节与实验基础。[pdf:E03][pdf:E04][pdf:E05][pdf:E06][pdf:E07]

成功后可把原本只按平均功率选型的 SST 扩展为能主动塑造端口频谱的电气系统，并研究频谱自由度如何随单元数增长。最大科学风险是相位自由度在加入电压均衡、实际损耗和变压器差异后几乎消失，留下的只是常见交错并联效果。最小实验应保持总功率、开关频率和器件参数相同，比较均匀交错、随机相位、面向目标频带设计三种配置；同时改变电容分组，检验频谱改变能否由“相位相关叠加”准确预测，而不只是增加等效电容造成的滤波。

与本文的差异落在问题、可控变量和评价对象：本文研究实时平台与设定跟踪，候选研究以相位相关性及连接分组为机制、以端口频谱为对象。本文引用的 Li–Bélanger 等效电路与 MARS 平台为数值实现提供基础，却不能回答这种联合设计是否已有先例。新颖性判断需要补读 DAB 交错调制、多端口纹波合成及 SST 阻抗塑形研究；现有全文证据足以提出候选，不足以宣称首创。[pdf:E08]

**Wild-card alternative：** 将各单元的热状态与电容荷电状态组成可交换的“单元角色”，通过物理串并联重组研究同一 SST 在多端口供能任务中的能力边界；它改变物理拓扑和任务分配，机制不同于载波相位合成。
