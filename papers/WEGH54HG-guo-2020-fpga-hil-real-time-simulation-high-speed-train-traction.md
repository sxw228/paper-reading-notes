## § 1 — 研究问题与重要性

高速列车牵引控制单元（TCU）和辅助控制单元（ACU）在开发早期不能直接接到真实牵引系统上试：软硬件错误没排干净，很多故障和极限工况在实验室也做不出来。HIL 把变流器模型放进实时仿真器、与真实控制器闭环，是这一阶段的标准手段。论文的具体问题是：在一台 dSPACE 仿真器上，怎样把 25 kV 牵引变压器、双四象限整流器（4QC）、牵引逆变器、感应电机和软开关辅助 DC–DC、辅助逆变器组成的整套牵引系统做成 HIL 模型，并让变流器部分以 100 ns 固定步长在 FPGA 中运行。[pdf:E01]（PDF 物理页 1，Abstract）

难点来自两头。CPU 仿真器步长通常在 40–100 μs，一个步长里会塞进多次 PWM 开关事件，波形出错；FPGA 能把步长压到亚微秒，但 FPGA 上的变流器建模本身很难：状态空间法的拓扑数随开关数指数增长，受控电流源法要迭代，ADC（associate discrete circuit）法矩阵固定、效率高，却在开关动作时引入人工暂态和额外损耗，而开关导纳 GS 的选取过去靠试凑。[pdf:E02]（PDF 物理页 1，Introduction）价值在于：给出一条把整车级牵引系统落到商用 dSPACE + Virtex-5 平台、步长 100 ns 的工程路线，并把 ADC 法最依赖经验的参数 GS 变成可以事先算出的量。

## § 2 — 前人工作与不足

论文把 FPGA 变流器建模分成三条路线：状态空间法按开关组合枚举网络方程，开关一多，拓扑数指数膨胀，FPGA 存不下也切不动；受控电流源法精度高，但每步需要迭代，计算量不适合 FPGA；ADC 法把开关等效成“导通时的小电感、关断时的小电容加阻尼电阻”，网络矩阵在所有开关状态下保持不变，H⁻¹ 可以离线求好。[pdf:E02][pdf:E05]（PDF 物理页 1，Introduction；物理页 3，Section 3.1）

ADC 法的缺陷是物理性的：开关状态切换时，储存在等效小电容或小电感里的能量被直接丢掉，表现为人工暂态和额外开关损耗。GS 取值决定这部分误差的大小。已有做法是预设若干 GS 候选，与基准仿真逐个比较找最优值，效率很低。[pdf:E02]（PDF 物理页 1，Introduction 右栏）这个缺口之所以存在，是因为 GS 的最优值依赖工作点电压、电流，早期工作把它当成数值参数调，而没有写出损耗关于 GS 的解析式。

本文与同一课题组的两篇前作关系紧密：参考文献 [5]（Liu, Guo 等，IEEE TTE 2018）已经做过高速列车的系统级 FPGA HIL，[10]（Guo, Yuan, Tang 等，Energies 2018）已经研究过 ADC 建模的优化方法；GS 选取的已有方法则以 [20]、[21] 为代表。[pdf:E16]（PDF 物理页 8，参考文献列表）本文正文没有逐条说明相对 [10] 新增了什么，从 PDF 内容看，新增部分集中在 GS 的损耗极值解析式、五子系统状态变量分网和整车级多仿真器集成。

第二个缺口是 FPGA 上的矩阵规模。整套辅助变流器若作为一个 MNA 系统求解，矩阵维数大、乘加链长。论文提出在一端口元件（电感或电容）处切开网络，并称之为“无仿真延迟的解耦”。[pdf:E06][pdf:E09]（PDF 物理页 4，Section 3.3；物理页 5，Eq. (20)–(21) 与 Fig. 10）

## § 3 — 重建作者的思考路径

出发点是一个具体的工程画面：dSPACE 平台已经有 DS1006 多核 CPU 板和 DS5203 Virtex-5 FPGA 板，两台仿真器之间有 1.25 Gbit/s 光纤。慢动态的部分（电机运动方程、牵引变压器、启动时序逻辑）本来就不需要纳秒步长，放 CPU 以 60 μs 运行；只有开关密集的变流器需要 FPGA。于是第一步是按动态快慢切分，而不是把一切都塞进 FPGA。[pdf:E03]（PDF 物理页 2，Section 2）

第二步，在 FPGA 内选 ADC 法，因为固定矩阵意味着 H⁻¹ 离线算好，运行时只剩矩阵–向量乘。ADC 的已知代价是切换时丢能量，作者顺着这个物理图像走：导通时丢的是等效电容能量 0.5CV²，关断时丢的是等效电感能量 0.5LI²，而等效 C 与 L 都由 GS 和步长 h 决定。损耗于是写成 GS 的显式函数，一个方向随 GS 增大、另一个方向随 GS 减小，中间必然有极小值。[pdf:E07]（PDF 物理页 4，Eq. (15)–(18)）

第三步是矩阵规模。整套辅助变流器含半桥、ZCS DC–DC、三相逆变器、LC 滤波和电机，若联立求解，FPGA 上的乘加链太长。电路中本来就有大电容 Co、滤波电感 Laux 和隔离变压器，这些元件两侧的量天然是“状态”，用上一步的状态值当作受控源，就能把网络切成五个子系统各自求解。这是 EMT 中基于状态变量的分网思路，作者把它称作无延迟解耦。[pdf:E09]（PDF 物理页 5，Eq. (20)–(21)，Fig. 10）

## § 4 — 核心 Intuition

ADC 开关模型每次切换都丢掉一份等效储能，丢多少由 GS 决定：GS 大，关断态的等效电容大，导通时丢的电容能量多；GS 小，导通态的等效电感大，关断时丢的电感能量多。两者平衡处就是最优 GS，结果等于开关电流有效值除以直流电压，可以在建模前从额定工作点直接算出。[pdf:E07]（PDF 物理页 4，Eq. (18)–(19)）

网络规模的问题用储能元件的状态切断：电感电流和电容电压在一个步长内由上一步的量显式推出，子系统之间只交换这些状态，每个子系统就能用自己的小矩阵独立求解。[pdf:E09]（PDF 物理页 5，Eq. (20)）

## § 5 — 具体方法与完整 Pipeline

以辅助变流器为例，完整流程如下。

1. **平台与多速率划分。** 仿真器 1 在多核 CPU 的不同核上运行 MASTER（牵引主电路）和 SLAVE_D（变压器模型、启动时序），仿真器 2 运行 SLAVE（辅助变流器）。CPU 侧步长 h1 = 60 μs，FPGA 侧变流器步长 h2 = 100 ns，两种步长之间经外设高速总线交换数据。[pdf:E03]（PDF 物理页 2，Section 2；Fig. 3–4 见物理页 3）
2. **ADC 开关模型。** 每个开关等效为导纳 GS 并联历史电流源 jS。用后向欧拉离散，GS = (R + h/C)⁻¹ = h/L，保证导通、关断两种状态的导纳相同，MNA 矩阵 H 恒定；jS 在导通时等于 −iSⁿ，关断时等于 GS(vSⁿ − R iSⁿ)。[pdf:E05]（PDF 物理页 3，Eq. (1)–(3)，Fig. 5）
3. **开关状态机。** 二极管按 vD > 0 与 iD ≤ 0 在 ON/OFF 之间转移；IGBT 带反并联二极管，门极信号 S = 0 时由端电压和支路电流决定处于 OFF、正向导通或反向导通，状态机直接映射到 FPGA 逻辑。[pdf:E05]（PDF 物理页 3，Fig. 6）
4. **离线求最优 GS。** 按 Eq. (18) 由额定工作点电流、电压算出 GS，本例 GS = idc_aux / udc_aux = 0.261 S。[pdf:E07]（PDF 物理页 4，Eq. (19)）
5. **状态变量解耦。** 在 Co、Laux 和变压器处切开，辅助变流器被分成五个子系统：半桥、ZCS DC–DC、三相逆变器、LC 滤波、感应电机。变压器接口上，副边电压 v2secⁿ⁺¹ = m·v1priⁿ⁺¹ 取同一步的原边电压，原边电流 i1priⁿ⁺¹ = m·i2secⁿ 取上一步的副边电流。[pdf:E09]（PDF 物理页 5，Eq. (21)，Fig. 10–11 见物理页 5–6）
6. **子系统 MNA 与 FPGA 实现。** 各子系统写成 Eq. (22)–(25) 的小规模 MNA 方程，在 FPGA 中以 Fig. 13 的数据流连接，接口量经 z⁻¹ 寄存器传递。作者说明每个子系统内的加法、移位和选择逻辑能在一个时钟周期内完成。[pdf:E10][pdf:E11]（PDF 物理页 5 右栏；物理页 6，Fig. 13）
7. **定点化与 HLS。** 先定义电压、电流基值把矩阵标幺化，再选 Q 格式做定点运算，最后用 Vivado HLS 从 C/C++ 描述生成 HDL，自动做流水与并行，封装为 IP 接入 dSPACE。[pdf:E10]（PDF 物理页 5，Section 4 三步流程；物理页 6，Fig. 14）

输入是 TCU/ACU 发出的 PWM 与继电器信号，输出是经 DAC 送回控制器的电压、电流模拟量。论文没有报告 FPGA 时钟频率、每个 100 ns 步长内的时钟周期数、Q 格式的具体位宽和各子系统的延迟分解。

## § 6 — 核心数学推导（无形式化数学则跳过）

**ADC 开关模型。** 开关导通时看作小电感 L，关断时看作小电容 C 串联阻尼电阻 R。后向欧拉下电感的伴随模型是导纳 h/L 并联历史电流源，电容串电阻的伴随模型是导纳 (R + h/C)⁻¹ 并联历史电流源。令两者相等，就得到 Eq. (1) 的匹配条件 GS = (R + h/C)⁻¹ = h/L，此时无论开关状态如何，节点导纳矩阵中的这一项都是 GS，H 不随开关变化，Hxⁿ⁺¹ = bⁿ⁺¹ 中的 H⁻¹ 可预存。[pdf:E05]（PDF 物理页 3，Eq. (1)–(3)）直觉上，开关状态只改变历史电流源 jS 的更新公式，而不改变网络“骨架”。

**切换时丢掉的能量。** 以逆变器一个桥臂为例：第 n 步 sw1 关断，等效电容上储能 EC = 0.5·C·Vdc²，并以并联电流源 jSⁿ = GS·Vdc 的形式存在；第 n+1 步 sw1 导通，它变成电感，历史源按导通公式取 jSⁿ⁺¹ = −isw1ⁿ = 0，电容能量被整体丢弃。反方向同理，导通时电感储能 0.5·L·iload² 在关断时被丢弃。[pdf:E07]（PDF 物理页 4，Eq. (6)–(13)，左栏）

**损耗关于 GS 的函数。** 所有开通、关断事件丢掉的能量总和是 Eloss = Σ0.5·C·vsw² + Σ0.5·L·isw²（Eq. (14)）。代入 C = h·GS（忽略 R）和 L = h/GS，得到
Eloss(GS) = Σⱼ 0.5·h·[vswⁿ(j)]²·GS + Σᵢ 0.5·(h/GS)·[iswⁿ(i)]²（Eq. (15)）。
第一项随 GS 线性增大，第二项与 GS 成反比。对 GS 求导令其为零，得到 GS = √(Σᵢ[iswⁿ(i)]² / Σⱼ[vswⁿ(j)]²)（Eq. (16)）。[pdf:E06][pdf:E07]（PDF 物理页 4，Eq. (14)–(16)）

**化简到工作点。** 大多数变流器的开通、关断次数相等，导通时开关电流等于负载电流，关断时开关电压等于直流电压，于是 Eq. (16) 化为 GS = √((1/n)·Σ[iload(i)]²) / Vdc = iload,RMS / Vdc（Eq. (18)）。代入 Table 1 参数得到 GS = idc_aux / udc_aux = 0.261 S（Eq. (19)）。这里 Eq. (19) 用的是辅助 DC–DC 的输出电流与电压之比，而验证对象是辅助三相逆变器的一个桥臂，从 RMS 电流到直流比值的替换论文没有展开。[pdf:E07]（PDF 物理页 4，Eq. (17)–(19)）

**状态变量解耦。** 在电感和电容处用前向欧拉更新状态：
iLⁿ⁺¹ = iLⁿ + (h/L)(v1ⁿ − v2ⁿ)，vCⁿ⁺¹ = vCⁿ + (·)(i2ⁿ + i3ⁿ)（Eq. (20)）。
原文电容一行印作 C/h，按量纲应为 h/C。[pdf:E09]（PDF 物理页 5，Eq. (20)）右端只含第 n 步的量，因此第 n+1 步的 iL、vC 在子系统求解之前就已知，可以作为电流源或电压源注入两侧子系统。这是 FE 显式格式的性质，接口元件的积分精度从后向欧拉的一阶隐式变成一阶显式，稳定性变为条件稳定。

变压器接口 Eq. (21) 是另一种结构：v2secⁿ⁺¹ = m·v1priⁿ⁺¹ 用同一步的原边电压，i1priⁿ⁺¹ = m·i2secⁿ 用上一步的副边电流。[pdf:E09]（PDF 物理页 5，Eq. (21)）因此子系统 1 必须先于子系统 2 求解，而副边电流对原边的反馈延迟一步。这一步延迟落在漏感电流 i22 上，由于漏感电流在 100 ns 内变化很小，误差被压低，但它仍是一个真实的接口滞后。

## § 7 — 实验设计与结论

**问题一：最优 GS 公式是否给出最小损耗？** 实验在 MATLAB 离线仿真中把 GS 从 0.1 扫到 1，统计总开关损耗。结果损耗曲线在 GS = 0.2614 处最低（0.4561%），与 Eq. (19) 的 0.261 S 吻合。[pdf:E08]（PDF 物理页 4，Fig. 8）

**问题二：最优 GS 是否提高波形精度？** 以 SimPowerSystems（ODE4，100 ns）为参考，比较 GS = 0.1、0.5 和最优值下逆变器侧与负载侧 A 相电流的相对误差。最优 GS 下相对误差不超过 1%，另外两个取值误差更大。[pdf:E04][pdf:E08]（PDF 物理页 2，Table 2；物理页 4，Fig. 9 与右栏正文）这一组对比是离线的，不涉及 FPGA 定点和解耦。

**问题三：整车 HIL 能否复现真实系统行为？** 在 dSPACE 平台上接入真实 TCU、ACU，做 4QC 空载启动（约 0.7 s 内直流电压从 2600 V 升到 3600 V）、双 4QC 交错调制下的电流谐波（15、17、19、21 次在合成电流中被抵消）、满载下变压器副边电流与实测对比、牵引电机在中心 60° 同步调制不同脉冲数之间切换的定子电流、辅助 DC–DC 的 ZCS 波形与负载突变。[pdf:E12][pdf:E13][pdf:E15]（PDF 物理页 6 右栏；物理页 7，Fig. 17；物理页 8，Fig. 20）作者的结论是 HIL 与实验“无明显差异”，DC–DC 波形细节因未建二极管反向恢复而略有不同。[pdf:E13]（PDF 物理页 7 右栏末段）结论节把 100 ns 步长的解耦实现归结为实时仿真精度的来源。[pdf:E14]（PDF 物理页 8，Section 5）

**资源。** 牵引驱动系统占 DS5203 的 DSP 74%、slices 78%、flip-flop 61%；辅助变流器系统占 DSP 51%、slices 60%、flip-flop 53%（DSP 总数 640，slices 14,720）。[pdf:E11]（PDF 物理页 6，Table 3）

**覆盖范围。** 验证对象是一台具体的高速列车牵引系统（4QC 与逆变器开关频率 450 Hz，辅助半桥 4 kHz、谐振开关 8 kHz），平台是 dSPACE DS1006 + DS5203（Virtex-5），FPGA 步长 100 ns。[pdf:E04]（PDF 物理页 2，Table 1–2）HIL 与实测的对比全部是示波器波形叠看，没有数值误差指标；解耦模型与未解耦模型之间也没有对照。

## § 8 — Take-aways

**五句话：** 论文在 dSPACE 上搭了一套多仿真器、多步长的高速列车牵引 HIL 平台，慢动态放 CPU（60 μs），变流器放 FPGA（100 ns）。ADC 开关模型在切换时丢弃等效储能，作者把这部分损耗写成 GS 的显式函数。对 GS 求极值得到最优值等于开关电流有效值除以直流电压，可在建模前算出，离线扫描验证了极小点位置。网络在储能元件和变压器处按状态变量切成五个子系统，接口量用上一步状态或单向同步传递。整套模型经标幺化、定点化和 Vivado HLS 实现，HIL 波形与实测在波形层面一致。

**三句话：** 最优 GS 有解析式 GS = iload,RMS / Vdc，来自损耗对 GS 的极值条件。状态变量分网把辅助变流器拆成五个小 MNA 系统，让 100 ns 步长在 Virtex-5 上可行。验证以整车 HIL 波形为主，精度对比是离线的。

**一句话：** 这是一篇把 ADC 开关导纳从经验调参变成解析选取、并用状态变量分网把整车牵引系统落到 100 ns FPGA HIL 的工程论文。

## § 9 — 最脆弱的假设

最关键的假设是：**一个固定的 GS 能代表整个运行过程的最优值。** Eq. (18) 的推导把 Σisw² 和 Σvsw² 写成工作点的 RMS 电流和直流电压，得到单一 GS；而牵引系统的核心使用场景恰恰是工况大范围变化：启动、满载、制动、同步调制脉冲数切换、辅助负载突变。[pdf:E07][pdf:E12]（PDF 物理页 4，Eq. (18) 及“与具体工作点相关”的说明；物理页 6，HIL 工况）论文自己在 Eq. (18) 后写明最优 GS 与工作点电压、电流有关，但 Eq. (19) 只按额定点算出 0.261 S，Fig. 8、Fig. 9 也只在这一个工作点验证。

如果负载电流降到额定值的 20%，按公式最优 GS 应降到约 0.05 S，而实际用的是 0.261 S，关断态等效电容偏大，导通瞬间丢弃的电容能量相对负载功率的比例会上升。论文的 HIL 波形覆盖了多个工况，但只给出波形叠看，看不出这部分误差随工况的变化。

第二个值得警惕的假设是状态变量接口的稳定性。Eq. (20) 用前向欧拉更新接口元件，Eq. (21) 的变压器电流延迟一步，这两者都不是无条件稳定的，论文没有给出任何步长或元件参数的稳定条件。本例中接口元件都是 mF、mH 级的大储能，与 100 ns 步长相比时间常数很长，问题不暴露；换一个接口元件，情况会不同（见 § 11）。

## § 10 — 最小复现实验

一周内最值得验证的是“单一最优 GS”在变工况下还剩多少优势。

- **数据与模型：** 用 Table 2 的辅助三相逆变器参数（直流 600 V，LC 滤波 Lauc = 0.21 mH、Cauc 取合理值，4 kHz 开关）在 Python 或 MATLAB 中实现 ADC 桥臂模型，h = 100 ns，按 Eq. (1)–(2) 更新历史源，参考解用理想开关的小步长仿真（例如 h = 5 ns 的分段线性模型）。[pdf:E04][pdf:E05]
- **实现：** 负载电流分别取额定值的 100%、50%、20%，对每个工况扫描 GS ∈ [0.02, 1] S，记录一个基波周期内的开关损耗与负载电流相对误差。
- **测量：** 各工况的实际最优 GS，与 Eq. (18) 预测值 iload,RMS/Vdc 的偏差；固定 GS = 0.261 S 时，各工况误差相对各自最优值的放大倍数。
- **判据：** 若各工况最优 GS 与 Eq. (18) 预测一致，且固定 0.261 S 在 20% 负载下误差仍接近最优，则论文的“建模前算一次”成立；若低载下固定 GS 的误差比最优值大一个数量级，则 GS 需要随工况设计，论文的单点验证不足以支撑整车 HIL 的精度结论。

## § 11 — 最强反例设计

攻击点是“无延迟解耦”的稳定性。前向欧拉更新一个无阻尼 LC 振荡时，每步的放大因子是 |1 + jhω| = √(1 + h²ω²)，相当于给振荡注入了约 σ ≈ hω²/2 的负阻尼。论文的接口元件是 Co（0.98 mF）和 Laux 这类大储能，与相邻元件构成的谐振频率低，hω 极小，负阻尼被电路中的电阻完全掩盖。[pdf:E04][pdf:E09]（PDF 物理页 2，Table 2；物理页 5，Eq. (20)）

反例是把切点放在一个小储能元件上。例如同一张 Table 2 中的变压器漏感 Lk = 1.27 μH 与谐振电容 Ca = 4.5 μF，谐振角频率约 4.2×10⁵ rad/s，h = 100 ns 时 hω ≈ 0.042，等效负阻尼 σ ≈ 8.8×10³ s⁻¹，时间常数约 0.11 ms。[pdf:E04]（PDF 物理页 2，Table 2）ZCS 谐振回路本身阻尼很小，如果在 Lk 或 Ca 处用 Eq. (20) 切开，谐振电流会在几个开关周期内被数值放大，而同一电路用后向欧拉整体求解是稳定的。实验设计：在辅助 DC–DC 的离线模型中分别在 Co（论文做法）和 Ca 处切开，保持 100 ns 步长，对比与整体求解的谐振电流包络。预期在 Ca 处切开时包络逐周期增长。

这个反例不否定论文的实际实现，它说明“无延迟解耦”的适用条件是接口元件满足 hω ≪ 1 且周围有足够阻尼，而论文把它表述成一般方法。同理，Eq. (21) 中副边电流延迟一步，若负载侧出现快速的电流阶跃（例如辅助逆变器短路故障），原边会在一步内看到错误的电流，故障工况的首峰值会偏差。

## § 12 — Follow-up Research Bet

**主 idea：时间错位的子系统流水执行——把电路接口的单向同步方向做成 FPGA 流水线方向。**

论文里有一个没被开发的现象：变压器接口 Eq. (21) 的耦合是有方向的，电压沿原边→副边在同一步传递，电流沿副边→原边滞后一步传递；储能元件接口 Eq. (20) 则在两个方向上都只用上一步的量。[pdf:E09]（PDF 物理页 5，Eq. (20)–(21)）Fig. 13 中子系统之间的接口信号也确实经过 z⁻¹ 寄存器传递。[pdf:E11]（PDF 物理页 6，Fig. 13）这意味着五个子系统在一个步长内的同步依赖构成一个有向无环图，反向边全部是跨步的。

**新的研究问题：** 能否让相邻子系统在时间上错开一步执行，子系统 k 计算第 n 步时，子系统 k+1 同时计算第 n−1 步，使一个仿真步长的硬件延迟从“各子系统延迟之和”变成“单个子系统的最大延迟”？

**首次使什么成为可能：** 当前实现里子系统 1 必须在子系统 2 之前求解，步长下限是串行链的总延迟。时间错位后，链上每一级都成为流水线的一级，步长只受最慢一级约束，子系统数量增加不再拉长步长。整车级系统（多台逆变器、多台电机）可以串成更长的链而不牺牲 100 ns 步长。

**因果链：** 同步依赖只沿正向 → 正向边的数据在第 n 步产生后立刻被下游在第 n 步使用，下游可以在上游之后一个流水级执行 → 把下游的时间索引整体后移一步，正向边变成跨级寄存器，反向边的滞后从一步变成两步 → 所有子系统在同一个时钟节拍里各自计算不同时间步 → 吞吐等于每级延迟的倒数。

**改变的设计变量：** 时间模型（子系统之间存在固定的时间偏移，仿真时间不再全局同步）；硬件映射（子系统按接口有向图排成 systolic 链）；分网标准（切点选择从“矩阵变小”变为“同步依赖方向一致、反向边落在慢状态上”）。

**论文依据：** 方法侧是 Eq. (21) 的同步单向电压传递与滞后电流反馈，以及 Eq. (20) 的全滞后状态接口；实验侧是 Table 3 中辅助变流器已占 DSP 51%、牵引系统占 74%，说明在 Virtex-5 上继续靠并行展开扩大规模已经接近资源上限，流水化是剩下的扩展方向。[pdf:E09][pdf:E11]（PDF 物理页 5；物理页 6，Table 3）

**最大收益与最大风险：** 收益是步长与子系统数量解耦，整车级牵引、多机并联系统可在单片 FPGA 上以亚微秒步长运行。风险是反向边滞后加倍后，接口误差和数值稳定边界都会恶化，§ 11 的负阻尼机制会更早出现；另外控制器看到的各子系统输出带有不同的时间偏移，需要在 DAC 输出侧对齐。

**区分核心机制与替代解释的最小实验：** 在辅助变流器五子系统链上实现两个版本——全局同步（论文做法）与逐级错位一步。测量 FPGA 最小可达步长和与 SPS 参考的电流误差。若错位版本的步长下降接近 1/5 而误差增幅小于 1%，说明收益来自流水化；若误差显著增大，则说明反向边滞后才是瓶颈，需要先把反向边安排到慢状态上。

**与已有工作的区别：** Yang 等 2024 的 delay-free decoupling 在同一步内联立求解少量边界电流，再做向量归约，目标是保留同步耦合；Ould-Bachir 等 2015 的 network tearing 在一个步长内完成分块求解；本批次中 Montaño 等 2020 的 latency-insensitive 设计让处理单元按数据到达自动同步，仍在同一个时间步内完成。上述工作都保持全局同一时间步，这里的主张是有意引入固定的时间偏移，把同步依赖的方向当作流水线方向，问题定义（步长受哪条路径约束）和时间模型都不同。

**Wild-card：** 把 GS 当作分网的设计变量而不是精度参数：为每个子系统选择 GS，使若干子系统的 MNA 矩阵 H⁻¹ 完全相同，从而让它们在 FPGA 上分时复用同一个矩阵乘核，用精度上的小代价换 DSP 资源的成倍节省。
